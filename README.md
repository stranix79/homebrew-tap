# stranix79/tap

Homebrew formulae for [Stranix](https://stranix.net) tools. Currently ships
[Deckhand](https://deckhand.show), HTML presentations written in Markdown.

```
brew install stranix79/tap/deckhand
```

Formulae build from the tagged source with Go; no bottles.

## Also by Stranix

- [stranix.net](https://stranix.net): the blog.
- [Deckhand](https://deckhand.show): HTML presentations written in Markdown, the tool this tap installs.
- [Chutag](https://chutag.stranix.net): QR tags for lost items (beta).
- [apps.stranix.net](https://apps.stranix.net): native macOS apps.
- [CODE79](https://code79.com): the devops workshop behind all this.
